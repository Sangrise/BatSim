BatSim 사용자 매뉴얼

BatSim은 PSpice 스타일의 회로 편집기와 Python 기반 배터리 / BMS 시뮬레이션 엔진을 결합한 도구입니다. 언제든 F1으로 이 매뉴얼을 다시 열 수 있습니다. GUI · 명령줄(CLI) · 확장(사용자 모델, 셀 데이터, 외부 SOC 알고리즘)을 모두 다룹니다.

1. BatSim 개요

BatSim은 두 가지 핵심을 결합합니다.

  • 편집기 — 부품을 드래그해 배치하고, 와이어를 그리고, 파라미터를 설정합니다.
  • 해석기 — 수정 절점 해석(MNA) 기반의 DC / 과도 해석기. 비선형 소자와 배터리 모델은 Newton 반복으로 처리합니다.
  • 배터리 / BMS — Rint, Thevenin, n-RC, SPM, DataDriven 등 플러그인 가능한 배터리 모델과 보호 / 밸런싱 / SOC 추정 BMS 블록을 함께 제공합니다.
  • CLI & 스윕 — 모든 시뮬레이션을 GUI 없이 터미널에서 실행할 수 있어, 파라미터 스윕으로 최적 조건을 찾기 쉽습니다.

2. 화면 구성

  • Components 도크(좌) — 부품을 드래그해 캔버스로 가져옵니다.
  • 캔버스(중앙) — 회로 편집 영역. 휠 = 스크롤, Ctrl+휠 = 줌, 빈 영역 드래그 = 러버밴드 다중 선택.
  • Inspector 도크(우) — 현재 선택된 부품의 파라미터.
  • Waveforms 도크(하) — 첫 과도 해석 후 자동으로 보이며 여러 플롯 패널을 호스팅합니다.
  • Outline 도크(우, 인스펙터 아래) — 현재 회로의 모든 부품 / 와이어 목록. 클릭하면 캔버스에서도 같이 선택되며, 상단 검색창에 id 또는 kind를 입력해 필터링할 수 있습니다. 복잡한 회로에서 붙여넣은 항목을 빠르게 다시 찾을 때 유용합니다.
  • 상태바 — 컨텍스트 힌트, 시뮬레이션 요약.
  • 메뉴 — File · Edit(Undo/Redo/복사/붙여넣기/블록) · Simulate · Help.

3. 5분 빠른 시작

  1. 팔레트에서 V, R, C, GND를 캔버스로 드래그합니다.
  2. 노란 핀에서 마우스를 누른 채 다른 핀까지 드래그해 와이어를 그립니다. 커서가 빈 공간에 있으면 흐린 점선, 유효한 타겟(핀 또는 와이어) 위에서는 밝은 실선으로 미리보기가 바뀝니다.
  3. V를 클릭 → 인스펙터에서 V 값을 5로 변경 후 Enter.
  4. Ctrl+R로 시뮬레이션 다이얼로그를 열고, Transient, t_end = 0.05, dt = 0.0005로 실행.
  5. 하단 Waveforms 도크에 V(N1), V(N2), I(V1) 파형이 표시됩니다.

6. 와이어 — 전체 작업 흐름

와이어 그리기

두 가지 방식 모두 사용 가능:

  • 드래그 — 핀(부품 모서리의 작은 노란 사각형)에서 마우스를 누르고, 끌어, 다른 핀에서 놓습니다.
  • 클릭-클릭 — 시작 핀을 클릭한 뒤, 종료 핀을 클릭. Esc로 취소 가능합니다.

드래그 중에는 직각(Manhattan) 미리보기 선이 커서를 따라옵니다.

  • 흐린 점선 — 빈 공간 위; 여기서 놓아도 와이어가 만들어지지 않습니다.
  • 밝은 실선 — 핀 또는 기존 와이어 위; 여기서 놓으면 연결됩니다.
중요: 와이어는 핀 또는 기존 와이어 위에 놓을 때만 생성됩니다. 빈 공간에서 놓으면 아무 일도 일어나지 않습니다 — 떠 있는(floating) 와이어 끝은 존재할 수 없습니다.

부품 본체 회피

라우터는 다른 모든 부품을 장애물로 취급하고 필요 시 직각 우회로를 선택합니다. 출발 / 도착 부품도 약하게 장애물로 포함되어, 와이어가 부품 본체를 가로지르지 않고 핀을 통해서만 들어옵니다. 예를 들어 좌측 전압원의 오른쪽 핀과 R-(R||C) 회로 우측을 연결할 때, 가운데 R을 가로지르지 않고 아래쪽으로 우회합니다.

꺾임(bend) 편집

와이어를 선택하면 흰색으로 변하면서 모든 내부 segment의 중간에 주황색 사각형 핸들이 표시됩니다. 핸들을 드래그하면:

  • 가로 segment는 세로로, 세로 segment는 가로로 슬라이드합니다. 그리드 간격은 20 px입니다.
  • 핀 바로 옆 segment를 슬라이드해도 핀 위치는 고정됩니다 — BatSim이 자동으로 L자 elbow를 삽입해 핀 끝점을 anchored 상태로 유지합니다. 따라서 모든 bend(핀에 가장 가까운 것 포함)를 자유롭게 이동할 수 있습니다.
  • 와이어 자체에서 Delete를 누르면 segment 하나가 아니라 와이어 전체가 삭제됩니다.

병렬 분기 (T-junction)

기존 와이어에서 분기를 만드는 방법:

  1. 핀에서 와이어를 시작합니다.
  2. 자유 끝을 기존 와이어 위에서 놓습니다.
  3. BatSim이 와이어 위에 정확히 작은 JUNCTION 점을 만들고 새 와이어를 거기에 연결합니다. 원래 와이어는 분할되지 않고 단일 segment로 그대로 유지됩니다.
JUNCTION은 항상 와이어 위에 있어야 합니다. 드래그하면 호스트 와이어를 따라서만 슬라이드되며, 와이어를 벗어날 수 없습니다. 호스트 와이어를 삭제하면 그 JUNCTION과 거기에 연결된 와이어들도 자동 삭제됩니다.

와이어 교차 표시

두 와이어가 교차할 때:

  • 전기적으로 같은 노드라면 녹색 점(JUNCTION 연결).
  • 단순히 시각적으로만 교차한다면 작은 아치 / hop으로 표시되어 서로 분리되어 있음을 나타냅니다.

7. 이동 · 회전 · 복사

이동

부품을 드래그해 옮기면 와이어가 자동으로 따라옵니다. 이동은 그리드에 스냅됩니다.

회전과 반전

  • 키보드: R = +90° 회전, M = 좌우 반전.
  • 마우스: 부품 우클릭 → Rotate 90° / −90° / Mirror.
  • 와이어가 끊어지지 않습니다. 회전 후 핀의 scene 좌표가 바뀌면 부품을 자동 평행이동해 와이어 끝이 핀을 따라가도록 합니다.

복사 / 붙여넣기

  • Ctrl+C: 선택된 부품과 그 부품들 사이의 와이어 전부를 복사합니다.
  • Ctrl+V: 현재 뷰 중앙에 새 ID로 붙여넣습니다.
  • 다른 BatSim 인스턴스 사이 붙여넣기도 됩니다 — 시스템 클립보드 텍스트가 BATSIM: 접두사 뒤에 JSON 형식으로 저장됩니다.

8. 재사용 가능한 블록

"블록"은 저장된 서브-회로로, 나중에 어떤 캔버스에든 다시 떨어뜨릴 수 있습니다.

  1. 재사용할 부품과 와이어를 선택합니다.
  2. Edit → Save selection as block… (또는 Ctrl+G) → 이름을 입력합니다.
  3. 블록은 ~/.batsim/blocks/<이름>.json에 저장됩니다.
  4. Edit → Insert block에 저장된 블록 목록이 나옵니다. 선택하면 현재 뷰 중앙에 새 ID로 붙여집니다.
  5. Edit → Open blocks folder로 해당 폴더를 열어 블록 JSON 파일을 다른 사용자와 공유할 수 있습니다.

9. 인스펙터

  • 숫자 — 입력 값은 자동으로 float으로 변환되고, 지수 표기(1e-3)도 가능합니다.
  • 불리언 — 체크박스로 표시됩니다.
  • 리스트 / 딕셔너리(예: OCV-SOC 표) — 인스펙터에서는 읽기 전용. data/cells/의 JSON에서 직접 편집하세요.
  • Tab 또는 Enter로 값 확정.

10. 배터리 모델과 셀 프리셋

BATTERY 부품은 모델(방정식 집합)과 선택적 셀 프리셋 (실제 셀의 파라미터 묶음)을 결합합니다.

드롭다운의미
cell (preset) data/cells/ 또는 ~/.batsim/data/cells/의 모든 JSON. 선택하면 capacity, R0, OCV 표 등이 자동 채워지며 모델 이름도 함께 설정됩니다. 63 Ah NCM/LFP 프리셋이 기본 포함됩니다.
model 플러그인 레지스트리에 등록된 모델. 빌트인: Rint, Thevenin (1-RC), n-RC, SPM, DataDriven.
chemistry Rint / Thevenin / n-RC에서 사용하는 OCV 곡선을 화학별로 선택합니다. NCM(완만한 slope, 3.50→4.20 V), LFP(20–90% 구간 ~3.30 V plateau), NCA, LCO, LTO(1.5–2.85 V), Generic. DataDriven 모델은 셀의 ocv_table을 직접 사용하므로 이 값은 무시됩니다.

모델 선택 가이드

  • Rint — 가장 빠름. V_t = OCV(SOC) − I·R0.
  • Thevenin — RC 한 쌍 추가, 단기 분극 표현.
  • n-RC — 다중 RC 쌍(빠름 + 느림). 일반적인 BMS 검증 수준.
  • SPM — 단순화된 단일 입자 전기화학 모델.
  • DataDriven — Python 코드 없이 OCV-SOC 표와 선택적 RC 쌍만으로 새 셀 추가 가능.
플로팅 회로 / 자동 접지 (BUS 권장)
실제 시스템처럼 BUS 컴포넌트(모드 = Grid / PLoad / ILoad)를 배터리에 연결하면 BUS의 음극 핀이 자동으로 시스템 0 V 기준이 됩니다 — GND 심볼이 따로 없어도 됩니다.
Grid는 변압기 너머의 전력망을 대표하는 stiff 전압원, PLoad는 정전력 부하, ILoad는 정전류 부하입니다. 세 가지 모두 같은 심볼이며 인스펙터의 mode 드롭다운으로 전환합니다.
BUS도 GND도 없는 옛 시트의 호환을 위해, 그런 경우에 한해 첫 PCONST/ICONST/IPATTERN/I 또는 BATTERY의 음극이 자동 접지로 선택됩니다.

TR — 이상적 권선비 결합기 (AC/DC 공용)

4-핀(p+, p−, s+, s−) 컴포넌트로, V(p+)−V(p−) = n · (V(s+)−V(s−)) 관계를 강제합니다 (n = 1차/2차 권선비). 전력 균형으로 I_s = −n · I_p가 자동 성립합니다.

엔진은 시간영역이므로 sine 입력을 그대로 받아 AC 변환기로 사용 가능합니다. 단, 자화/누설 인덕턴스는 모델링되지 않으며 순간 전압 스케일러로만 동작합니다. 1차 측과 2차 측 각각에 GRID/BUS/GND 기준이 있어야 행렬이 풀립니다.

AC 체인 — GRID · TR · PCS

실제 ESS와 같은 GRID(AC) → TR → PCS(AC↔DC) → BATTERY 구성을 그대로 그릴 수 있습니다.

  • GRID — 2-핀 sine 전원. V_rms, freq [Hz], phase_deg, bias 파라미터를 가집니다. pin 1(중성선)은 자동으로 노드 0에 접지됩니다.
  • PCS — 4-핀 컨버터 (AC+, AC−, DC+, DC−). 9가지 모드를 지원하며 모든 충/방전 프로파일을 PCS 인스펙터에서 직접 입력합니다.
    모드설명주요 파라미터
    V_DCDC 측 정전압 (CV 충전기)V_DC_set
    I_DCDC 측 정전류 (CC 충전기)I_DC_set
    P_DCDC 측 정전력P_DC_set
    CC정전류 (프로파일)I_set
    CV정전압 (프로파일)V_set
    CP정전력 (프로파일)P_set
    CCCVCC → V_max 도달 시 CV → |I|≤I_term 종지I_set, V_max, I_term
    CPCVCP → V_max 도달 시 CV → |I|≤I_term 종지P_set, V_max, I_term
    CYCLE스텝 리스트 순차 실행 (충방전 사이클)cycle_steps (JSON), cycle_repeat

    부호 규약 — + = 충전, − = 방전. cycle_steps는 JSON 배열로, 각 스텝마다 위 단일 모드 중 하나와 종지 조건(max_time, V_max, V_min, I_term)을 지정합니다. 예:

    [{"mode":"CC","I":10,"V_max":3.6,"max_time":600},
 {"mode":"REST","time":300},
 {"mode":"CP","P":-50,"V_min":2.5,"max_time":900}]

    cycle_repeat=N으로 N회 반복(0=무한) 가능합니다. AC 측은 η(eta) 손실을 반영한 등가 정전력 부하로 처리합니다. PCS의 AC−, DC− 두 핀은 모두 자동 접지되며 v1에서는 갈바닉 절연이 모델링되지 않습니다 — 절연이 필요한 케이스는 TR을 AC측에 두어 권선비 변환만 사용하세요.

  • dt 권장 — AC 한 주기당 20점 이상 → dt ≤ 1/(20·f) (50 Hz 1 ms / 60 Hz 0.83 ms).

11. BMS 블록

batsim_core.bms 패키지는 보호, 셀 밸런싱, SOC 추정기, 팩 컨트롤러를 제공합니다. Python 플러그인이나 드라이버 스크립트에서 배터리에 연결할 수 있습니다. batsim list-bms로 현재 사용 가능한 블록을 확인하고, ~/.batsim/plugins/에 직접 추가할 수도 있습니다.

12. 프로브와 측정 신호

  • PROBE를 임의의 노드에 떨어뜨리면 V(P1) 신호가 결과에 추가됩니다. 라벨은 P2, P3 … 로 자동 증가합니다.
  • IPROBE를 와이어 중간에 삽입하면 두 핀이 0 V "션트"로 동작하며 전류가 I(IP1)로 노출됩니다.
  • 프로브를 전혀 두지 않으면 모든 노드 전압과 전압원 전류가 자동으로 노출됩니다 — 빠른 탐색에는 편리하지만 큰 회로에서는 지나치게 많을 수 있습니다.

충/방전 패턴 컴포넌트 (배터리 테스트용)

  • ICONST — 정전류 부하/소스. 파라미터: I(A, 양수면 pin0→pin1 방향). 배터리에 연결하면 정전류 방전(+) 또는 충전(−)을 수행합니다.
  • PCONST — 정전력 부하. 파라미터: P(W, 양수=부하). 비선형 요소이므로 Newton 반복으로 풀립니다 (시작 추정이 어려우면 |V| < 0.5 V 구간에서 안정성을 위해 클램프).
  • IPATTERN — CSV 파형 전류원. 파라미터: csv 파일 경로(인스펙터의 「…」버튼으로 찾기 가능), scale 배율, repeat 반복 여부, I CSV가 비었을 때 사용할 기본값.
    CSV 형식은 헤더 없이 time_sec, value 두 열입니다. #으로 시작하는 줄은 주석으로 무시됩니다. 
    # 충방전 프로파일 예시
0,    0
60,  -2.0     # 1분간 2A 충전
3600, -2.0
3660,  0
4000,  1.0    # 1A 방전
프로브도 일반 부품처럼 이동 · 회전 · 복사 가능 하며 와이어가 유지됩니다.

13. 시뮬레이션 실행

Simulate → Run… (또는 Ctrl+R)로 다이얼로그를 엽니다. 다이얼로그는 선택한 모드에 대한 인라인 설명을 함께 표시합니다.

모드의미출력
DC operating point t=0의 바이어스 점만 계산. 캐패시터 open, 인덕터 short, AC 소스는 DC 값으로 고정. 노드 전압 스냅샷 (메시지 박스).
Transient 0→t_end 시간영역 적분, 스텝 dt. 비선형 소자/배터리는 Newton 반복. 전체 파형이 Waveforms 도크로 표시.

Auto from PCS cycle 버튼 — Transient에서 t_end 필드 옆 버튼을 누르면 시트 위 모든 PCS의 cycle_steps의 max_time·time을 합산하고 cycle_repeat를 곱한 값(여러 PCS가 있으면 최댓값)을 자동 입력합니다.

PCS cycle ≠ Run t_end — cycle은 “무엇을 할지”를, t_end는 “얼마 동안 시뮬할지”를 정합니다. 두 값은 독립적이며, t_end < cycle 총 시간이면 시뮬이 도중에 끊기고, 크면 cycle 종료 후 PCS가 DONE 상태(I=0)로 머무릅니다. cycle_repeat=0(무한)일 때는 사용자가 t_end를 직접 정해야 합니다.
배터리 전류 부호 규약: 양수 = 방전 (전류가 + 단자에서 나가는 방향). PCS setpoint 부호는 별도로 + = 충전, − = 방전입니다.

14. 파형 패널

  • 자동 V/I 분리 — 첫 시뮬레이션 직후 기본 패널이 자동으로 Voltage 패널 + Current 패널 두 개로 분리됩니다. V 신호는 위쪽 패널, I 신호는 아래쪽 패널에서 좌측 축으로 표시됩니다.
  • + Add plot — 새 패널 추가. 각 패널은 자체 신호 리스트를 가집니다.
  • Split V / I — 현재 패널 구성을 버리고 자동 V/I 분리 레이 아웃으로 다시 만듭니다.
  • 듀얼 Y축 — 패널 좌측 신호 리스트의 항목을 클릭할 때마다 상태가 Off → L(좌축) → R(우축) → Off로 순환합니다. 좌축은 실선, 우축은 점선 + 범례에 "(R)" 태그로 표시됩니다. 예: 같은 패널에 V와 I를 좌/우로 동시에 띄울 수 있습니다.
  • All→L / None — 패널의 모든 신호를 좌축에 한 번에 배치하거나 모두 끕니다.
  • × Remove — 패널 삭제(최소 1개는 항상 유지).
  • 스플리터 바를 드래그해 패널 높이를 조절합니다.

16. BatSim 확장하기

독립적인 세 가지 확장 방법(난이도 순).

16.1 셀 프리셋 (데이터 파일만)

data/cells/MyCell.json (또는 사용자별로 ~/.batsim/data/cells/MyCell.json):

{
  "name": "MyCell-2Ah",
  "model": "DataDriven",
  "params": {
    "capacity_Ah": 2.0, "soc0": 1.0, "R0": 0.025,
    "RC_pairs": [[0.012, 1500], [0.020, 8000]],
    "ocv_table": [[0.0, 2.9], [0.5, 3.7], [1.0, 4.18]]
  }
}

BatSim 재시작 → 인스펙터의 cell (preset) 드롭다운과 batsim list-cells에서 보입니다.

16.2 새 배터리 모델 (Python 플러그인)

~/.batsim/plugins/에 Python 파일을 떨어뜨립니다:

from batsim_core.models.base import BatteryModel
from batsim_core.plugins.registry import register_battery_model

@register_battery_model("MyChem")
class MyChemModel(BatteryModel):
    def __init__(self, capacity_Ah=2.0, soc0=1.0, alpha=0.5):
        super().__init__(capacity_Ah, soc0)
        self.alpha = alpha
    def terminal_voltage(self, t, dt):
        return 3.0 + self.alpha * self.soc

다른 폴더에서 가져오려면 환경 변수 BATSIM_PLUGIN_PATH 를 설정하세요. batsim list-models로 등록 확인.

16.3 외부 SOC 알고리즘

임의 위치의 my_soc.py:

from batsim_core.soc import register_soc_algorithm

@register_soc_algorithm("MyEKF")
class MyEKF:
    def __init__(self, capacity_Ah=2.5, soc0=1.0): ...
    def step(self, I, V, dt) -> float:
        ...
        return self.soc

데코레이터 없이도 메서드 시그니처가 정확히 step(self, I, V, dt)인 클래스는 자동 등록됩니다.

batsim soc-eval --script my_soc.py \
                --algorithm MyEKF CoulombCounter \
                --cell INR18650-25R --current 1.0 --t-end 1800

출력 표에는 알고리즘별 RMSE와 최종 SOC가 함께 나옵니다.

17. 문제 해결

증상원인 / 해결
"Singular matrix" 시뮬레이션 오류 고립 노드 또는 GND 누락. 모든 노드가 GND까지 DC 경로를 가져야 합니다. 프로브로 확인하세요.
배터리 전압 변화 없음 capacity_Ah가 너무 크거나 t_end가 너무 짧음. batsim cell-test … --csv discharge.csv 로 확인하세요.
와이어가 부품 본체를 가로지르는 듯 보임 이제는 발생하지 않아야 합니다 — 양쪽 끝과 중간 부품 모두 장애물입니다. 발생하면 .batsim 파일과 함께 제보해 주세요.
JUNCTION이 와이어에서 떨어진 것처럼 보임 발생할 수 없습니다 — JUNCTION은 호스트 와이어 위로만 제한되며, 호스트 와이어가 삭제되면 함께 제거됩니다.
새 모델 / 셀이 UI에 보이지 않음 BatSim 재시작. 데이터 파일은 data/cells/ 또는 ~/.batsim/data/cells/에 있어야 합니다.
외부 SOC 스크립트가 등록되지 않음 데코레이터를 쓰지 않을 경우 메서드 이름과 시그니처가 정확히 step(self, I, V, dt)여야 합니다.
